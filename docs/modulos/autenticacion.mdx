# Autenticación

Para interactuar con la API y continuar con los siguientes pasos del sistema, es necesario autenticar cada petición mediante un token **JWT (JSON Web Token)**.

---

## 1. Obtener el Token de Acceso

Realiza una petición `POST` al endpoint de autenticación con tus credenciales.

### Petición (`POST /api/v1/auth/login`)

```bash
curl -X POST [https://api.tudominio.com/v1/auth/login](https://api.tudominio.com/v1/auth/login) \
  -H "Content-Type: application/json" \
  -d '{
    "email": "usuario@ejemplo.com",
    "password": "tu_contraseña"
  }'
```
