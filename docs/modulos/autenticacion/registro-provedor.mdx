# HU01: Registro mediante Proveedores Externos (OAuth)

Este submódulo permite a los usuarios autenticarse e inscribirse en la plataforma **SyncTeam** mediante proveedores de identidad externos de confianza, como **Google** y **GitHub**, simplificando el flujo de acceso sin necesidad de ingresar contraseñas manualmente.

---

| **Dependencias**        | Configuración previa de OAuth/Firebase Authentication                               |

---

## ⚙️ Reglas de Negocio y Validación (RF2)

1. **Proveedores de Autenticación Soportados:**
   - **Google / Gmail**
   - **GitHub**

2. **Vinculación y Persistencia:**
   - El sistema vincula automáticamente la cuenta generada por el proveedor externo con el perfil del usuario correspondiente en la base de datos de **SyncTeam**.
   - Se aplican las mismas validaciones previas de integridad: si el correo obtenido desde el proveedor externo ya se encuentra asociado a una cuenta existente, se mantiene la asociación o se emite el mensaje de verificación correspondiente.
