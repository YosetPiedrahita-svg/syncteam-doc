# HU01: Registrar una Cuenta

Este módulo permite a los nuevos usuarios crear una cuenta dentro de la plataforma **SyncTeam** mediante registro tradicional (correo electrónico y contraseña) o autenticación de terceros (Google y GitHub).

---

| **Dependencias**        | Ninguna                                                                    |

---

## ⚙️ Reglas de Negocio y Validación (RF1)

1. **Campos Requeridos para Registro Directo:**
   - **Nombres:** Campo obligatorio.
   - **Apellidos:** Campo obligatorio.
   - **Correo Electrónico:** Formato válido (`usuario@dominio.com`) y no debe estar registrado previamente.
   - **Contraseña:** Mínimo 6 caracteres.

2. **Acciones Disponibles:**
   - **Registrarse:** Envía el formulario para su validación e inserción.
   - **Limpiar:** Restablece todos los campos del formulario a su estado inicial.
   - **OAuth (Google / GitHub):** Permite autenticación directa sin llenar el formulario manual.

### Muestra de Errores en Tiempo Real

Cuando el usuario intenta enviar el formulario con datos inválidos o incompletos, la interfaz resalta los campos en rojo y despliega los mensajes correspondientes:

- **Nombres:** _"Los nombres son obligatorios"_
- **Apellidos:** _"Los apellidos son obligatorios"_
- **Correo electrónico:** _"Formato de correo inválido"_
- **Contraseña:** _"La contraseña debe tener al menos 6 caracteres"_

![Errores de Validación](/img/registro-errores.png)

### Confirmación de Registro

Una vez ingresados los datos correctos y procesada la solicitud, el sistema emite una notificación emergente confirmando la creación:

### Validación de Correo Duplicado

Si el correo ingresado ya pertenece a un usuario existente en la base de datos, el sistema bloquea el registro y muestra la siguiente alerta:

- **Mensaje:** _"Este correo ya está registrado"_
